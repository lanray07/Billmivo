# Localisation preparation

`python tools/localise.py extract de-DE` creates a review file containing the Android strings, plural variants, planned Amazon listing copy and voice number words. The locale list distinguishes the international interface backlog from the storefront variants Amazon documents. [Amazon localisation guide](https://developer.amazon.com/docs/app-submission/distribute-your-app-internationally.html)

`python tools/localise.py translate de-DE` uses the official DeepL API with the key in `BILLMIVO_DEEPL_KEY`. The optional `BILLMIVO_DEEPL_HOST` selects the official free or pro API. The script sends only version-controlled product copy. It uses contextual terminology, protects placeholders, resumes cached entries and leaves machine translations marked for review. Check provider support for the requested target before running a batch. [DeepL translation and XML handling](https://developers.deepl.com/docs/translate/translating-xml)

Review each string in context, including plural cases, date and currency examples, and voice synonyms. Set the corresponding `reviewed` flag when reviewed, then run `python tools/localise.py render de-DE`. The script validates the current source fingerprint and placeholders before emitting Android XML, draft store metadata and voice words. Integrate those files into the Android resources, locale selection and voice dictionary in a reviewed change. On a Fire tablet, compare screen captures and test voice input separately from the interface locale.

The app supports English, French, Spanish, Arabic, German, Italian, Brazilian Portuguese, Dutch, Swedish and Polish. The Portuguese resources use Brazilian wording, and the manual selector requests `pt-BR`. Other Portuguese regions currently share that wording. Local store descriptions and screenshot assets cover United Kingdom English, French, Spain Spanish, German, Italian, Brazilian Portuguese, Dutch, Swedish and Polish. The checker requires all four Polish plural categories, and the Fire capture verifies quantity selection for 1, 2, 5, 12 and 22. [Amazon localisation guide](https://developer.amazon.com/docs/app-submission/distribute-your-app-internationally.html)

In the Console inspected on 21 November 2026, **App Setup → Store Listing Information → Description → Add/Remove localization** includes Dutch, Polish and Swedish. Its separate **Images and videos** picker does not offer those three locales, although Portuguese (Brazil) is available. Their genuine translated screenshots remain prepared locally. The binary-language checkbox list also omits Swedish. Do not claim these missing Console selections have been configured or replace another locale's screenshots to disguise the limitation.

The Fire screenshot command uses the instrumentation fixture `StoreScreenshotCapture`. Compose semantics drive navigation, and Android’s screenshot API captures the actual translated app at 1920 × 1200. Run `tools/capture-store-set.ps1` once for each prepared storefront locale, then `python tools/validate-amazon-package.py --raw deliverables/store-assets/amazon-raw`.
